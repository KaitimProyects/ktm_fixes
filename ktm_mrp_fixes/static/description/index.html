KTM MRP Fixes v18.0.1.0.0

Temporary patches for known Odoo MRP core bugs. Each fix is isolated, documented with its upstream reference, and designed to be removed as soon as Odoo ships the official solution.

📦 What is This Module?

KTM MRP Fixes is a rolling patch module that accumulates temporary workarounds for bugs found in Odoo's Manufacturing (MRP) core. Instead of touching the core or maintaining forks, fixes land here with clear upstream tracking so they can be cleanly removed once Odoo resolves them.

🔧 Active Fixes

MO truncates components to 40 when BOM has more lines Temporary — Pending upstream fix

Upstream reference: commit 3d43d9d9 (PERF: respect limit during onchange fetch)  |  Added: 2026-05-05

When a Bill of Materials has more than 40 components, creating or opening a Manufacturing Order silently truncates move_raw_ids to the first 40. This happens because commit 3d43d9d9 made the backend respect the limit attribute sent by the frontend list view — which defaults to 40 — causing the onchange snapshot to drop every component beyond that threshold.

Fix: Inherits mrp.mrp_production_form_view and sets limit="500" on the move_raw_ids list widget, raising the threshold above any realistic BOM size.
Remove when: Odoo core sets a sensible default limit on move_raw_ids or exposes a configuration key. Check the upstream issue tracker before each Odoo upgrade.

⚙️ Convention for New Fixes

Every fix added to this module must follow this pattern:

1. Document the root cause

Include the upstream commit hash or issue URL in a comment inside the XML/Python file.

2. Define a removal condition

State explicitly when the fix should be removed (e.g., "Remove when Odoo 18.1 is installed").

3. Update this document

Add an entry in the Active Fixes section above with the same upstream reference and date.

4. Move to "Removed Fixes" when resolved

Don't delete the entry — archive it below so there is a historical record of what was patched and why.

🗃️ Removed Fixes

🔧 Installation

Install the Module

  1. Ensure this module is in your Odoo addons path
  2. Update the apps list: Apps → Update Apps List
  3. Install KTM MRP Fixes from Apps → Manufacturing
